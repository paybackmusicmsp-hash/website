# Services and Pricing

## Services philosophy

This work is not presented as quick fixes or one-off random tasks.

It should be described as:
- structured
- connected
- consistency-driven
- built for long-term growth

Approved tone example:
"This isn’t about one-off services or quick fixes.
Everything is built around consistency and structure."

## Pricing model

Use ranges, not rigid packages.

Approved ranges:
- Artist Development: $200 – $600+
- Visual Production: $100 – $400+
- Platform / Web: $300 – $1500+
- Performance / Choreography: $150 – $700+

Required line:
"Each project is scoped individually to match what actually needs to be built."

Do not:
- invent package tiers
- rename pricing into branded tiers
- alter ranges unless explicitly requested
