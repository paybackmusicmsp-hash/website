# AGENTS.md

## Purpose

This repository is the production website for **MSP 790 Payback Music**.

Your job is to refine and maintain the site without breaking structure, responsiveness, JavaScript behavior, or brand identity.

This is **not** a generic SaaS site.
It is a music label platform with a strict design system called **Street Aero Dark**.

## Highest-priority rules

1. **Preserve structure**
   - Do not remove sections.
   - Do not redesign layouts.
   - Do not rename core classes unless absolutely necessary for a tiny additive enhancement.
   - Do not introduce new frameworks.

2. **Preserve brand identity**
   - Always use the full name **MSP 790 Payback Music** on first reference.
   - Do not abbreviate to `MSP` or `MSP 790` in public-facing copy.
   - Preserve culturally important phrasing exactly when marked as protected.

3. **Preserve content meaning**
   - Do not rewrite copy into corporate, generic, or buzzword-heavy language.
   - Keep text grounded, human, direct, and intentional.
   - If text is already good, leave it alone.

4. **Work incrementally**
   - Make small, controlled changes.
   - Prefer shared CSS refinements over page-specific hacks.
   - Do not improvise new design directions.

## Visual system summary

Use **Street Aero Dark**:

- dark layered surfaces, not flat black
- red as the dominant accent
- controlled glow, never neon
- subtle depth and edge-lighting
- alive, but not busy
- premium, not flashy
- structured, not corporate
- aero influence through light, surface, and interaction, not bright color flooding

## Color-role summary

Red is dominant.
Blue/purple/green are only subtle role-based accents, mostly on interaction:

- red = primary / brand / strongest action
- blue = system / informational / secondary
- purple = creative / artist / media
- green = success / confirmation only

These colors must feel like light, not paint.
