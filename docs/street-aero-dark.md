# Street Aero Dark

## Core idea

Street Aero Dark combines:
- street energy
- controlled dark aero polish
- premium, layered surfaces
- subtle environmental life

It should feel:
- grounded
- real
- structured
- alive
- slightly aggressive, but controlled

It should not feel:
- generic SaaS
- flat minimalism
- cyberpunk neon
- glassmorphism
- corporate dashboard

## Material rules

- Use layered dark surfaces, not pure black emptiness
- Panels/cards should feel dimensional and slightly armored
- Add subtle inner depth or tiny gradients
- Add faint edge-lighting instead of loud fills
- Avoid visible heavy borders and avoid glossy plastic look

## Glow rules

Glow is hierarchical:
- strongest on major headings and key focal points
- moderate on key interactive elements
- minimal on secondary text
- none on body text

Glow must remain:
- tight
- soft-edged
- controlled
- readable

Never use:
- giant blur halos
- fuzzy text
- global glow spam

## Motion rules

The site should feel alive, but controlled:
- fast smooth transitions
- subtle hover lift
- faint reveal motion if already supported
- extremely subtle background life only

Do not add:
- bouncy motion
- flashy animation
- long delays
- distracting loops

## Panel identity

Panels should not be red-filled boxes.
Panels should be:
- dark
- dimensional
- edge-lit
- slightly reactive on hover

Hover can reveal more energy than static state.
