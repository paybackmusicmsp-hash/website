# DaFont Core Font Notes

This folder is a shortlist of DaFont picks for the MSP site.

Goal:
- keep a small, intentional font system
- keep only fonts that appear usable for commercial work
- keep the bundled readme/license files where available

## Recommended Core Set

### Draco
- Best use: hero wordmarks, artist names, major campaign text
- Why: fastest and most polished "street performance" option in this pack
- Local font file: `Draco/extracted/Draco.otf`
- Local usage note: `Draco/extracted/Read me.txt`
- Usage note verified: personal and commercial use allowed

### Majanan
- Best use: buttons, nav, chips, badges, compact labels
- Why: strong condensed sans that still reads cleanly in UI
- Local font files:
  - `Majanan/extracted/Majanan.otf`
  - `Majanan/extracted/Majanan.ttf`
  - `Majanan/extracted/Majanan.woff`
- Local usage note: `Majanan/extracted/Read This Fist.txt`
- Usage note verified: "100% Free for personal and commercial use"

### Medel
- Best use: body copy, secondary UI text, readable supporting text
- Why: most stable readable sans in this pack for paragraphs and utility text
- Local font file: `Medel/extracted/Medel.ttf`
- Local usage note: `Medel/extracted/Information.rtf`
- Usage note verified: free for personal and commercial use

### Hansief
- Best use: section headlines, promo blocks, occasional display moments
- Why: strong vintage-modern display with more personality than a normal headline font
- Local font files:
  - `Hansief/extracted/Hansief.otf`
  - `Hansief/extracted/Hansief Rough.otf`
- Local usage note: `Hansief/extracted/READ ME.pdf`
- Usage note verified from bundled PDF:
  - personal and commercial work allowed
  - webfont use allowed
  - fixed-size image use allowed
  - do not redistribute, modify, or create derivative font files themselves

### Leteske
- Best use: mottos, gothic accent lines, slogan text, dark brand moments
- Why: best blackletter-style accent option without turning the whole site unreadable
- Local font file: `Leteske/extracted/leteske Final.otf`
- Local page note mirror: `Leteske/extracted/PAGE-NOTE.txt`
- Usage note verified from DaFont page note:
  - commercial use is fine
  - author says "use it however you like"

## Practical Site System

Use this system if we wire these into the site:

- `Draco`: hero names and special campaign headlines
- `Hansief`: major section headlines and promo-style title blocks
- `Majanan`: nav, buttons, chips, labels, small uppercase UI
- `Medel`: paragraph text, forms, supporting copy, utility text
- `Leteske`: motto text like `Trust No One`, `Owe No One`, and dark accent phrases

## Notes

- `Gothic 45` was on the original shortlist, but the DaFont download did not return a usable archive during this pass, so it is not included here.
- For `Leteske`, the download only included the font file, not a bundled readme/license, so the local `PAGE-NOTE.txt` mirrors the usage note from the DaFont page.
- DaFont labels are helpful, but the bundled readme/license should still be the source you trust first when it exists.
